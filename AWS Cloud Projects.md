1. Cloud-Based E-Commerce Platform for hospital services for our Client - Aster Multi Speciality Hospital.

This project to builds an online E-commerce platform for hospital services for our Client – Aster Multi speciality Hospital. It is a Cloud-Based healthcare application designed to provide online services such as medicine ordering, health packages purchase, appointment booking. The application is hosted 
on Amazon EC2 to provide scalable and reliable computing resources. Using Amazon RDS to store patient records, order details, transaction data. Medical reports and product images are stored in 
Amazon S3 for efficient storage and retrieval. Amazon CloudFront is used to deliver content quickly and securely to users. We managed application deployment and maintenance are simplified using AWS 
Elastic Beanstalk. Secure access control through AWS Identity and Access Management.

2. Serverless Application - Greenfield International School
 
This project is a serverless school management portal developed on AWS to manage student information, admission applications, and attendance records.
The solution uses AWS managed services, eliminating the need to manage servers and providing automatic scalability, high availability, and cost efficiency.
