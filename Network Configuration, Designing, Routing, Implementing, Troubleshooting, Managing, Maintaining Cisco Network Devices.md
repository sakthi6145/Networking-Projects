1. Small Office Network Design and VLAN Implementation for our Client - SpiterTech Solutions.

This Project designing and configuring a small office network setup for our Client - Spiter Tech Solutions. VLAN were created to separate departments and inter-VLAN routing was implemented, Trunking port IEEE 802.1Q tagging using carries traffic for multiple VLAN over a single physical link. Router on a Stick to enable communication between multiple VLANs. DHCP server was configured for automatically IP address assignment. We applied network security features like Port Security, Bridge Protocol Data Unit( BPDU ) Guard and disabled unused ports. Network connectivity and configuration were verified using troubleshooting tools such as ping, traceroute and show vlan commands.

2. College campus network design and configuration - Client Dindori College of Nursing

Designed and Configured a college campus network connecting multiple departments such as Admin, Library, Labs for our Client. Implemented VLANs and Variable Length Subnet Mask VLSM subnetting for efficient IP address allocation and configured inter-VLAN routing for communication between departments. We Setup access point for wired and wireless networks using IEEE 802.11 WLAN standard Wi-Fi Protected Access WPA2 for students and staff, guest Wi-Fi network with internet only access restricted using Access Control List ACL. Configured DHCP for automatic IP management and DNS services for access Websites. Implemented Spanning Tree Protocol STP for network resilience and Simple Network Management Protocol SNMP for network Reliability and Monitoring for our Client.
